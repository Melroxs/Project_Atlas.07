# File Versioning Schema---PurposeMaintains complete version history for all managed files.---Tablesfile_versionsversion_changesversion_diffs---## file_versionsColumnsiddocument_idversion_numberstorage_pathchecksumchange_summarycreated_bycreated_at---Business RulesVersions immutable.Rollback creates a new version.Every version references its predecessor.
