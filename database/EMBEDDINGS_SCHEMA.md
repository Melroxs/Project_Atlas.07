# Restoration Intelligence Rules1. Every Supplement belongs to one Claim.2. Every Estimate Version belongs to one Supplement.3. Line Items belong only to one Estimate Version.4. Historical Estimate Versions are immutable.5. Every AI Decision references supporting Evidence.6. Every Evidence object may support multiple Line Items.7. Compliance checks are executed against versioned rules.8. Atlas Memory is scoped and tenant-isolated.9. Knowledge Graph edges are directional and weighted.10. Every AI-generated record stores:    - Model name    - Model version    - Prompt version    - Confidence score    - Generation timestamp11. Xactimate pricing snapshots are preserved for auditability.12. No AI recommendation may be presented without traceable supporting evidence.13. All restoration intelligence data is protected by Row-Level Security and inherits organization ownership.
