# Prompt Management Schema---PurposeStores prompt templates, versions, variables, and deployment history.---Tablesprompt_templatesprompt_versionsprompt_variablesprompt_deploymentsprompt_tests---## prompt_templatesColumnsidnamecategorydescriptionownerstatuscreated_atupdated_at---## prompt_versionsColumnsidtemplate_idversion_numberprompt_textmodel_familytemperaturemax_tokensis_activecreated_at---Business RulesPrompt versions are immutable.Only one active version per template.All AI requests reference the prompt version used.
