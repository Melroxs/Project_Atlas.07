Project OverviewVisionProblem statementMVP goalsTarget usersCore workflows2. Non-Functional RequirementsSecurityPerformanceScalabilityReliabilityMaintainabilityAccessibility4. System ArchitectureWe'll map how every major component interacts:Frontend    │    ▼API Layer    │    ▼Business Logic    │ ┌──┴───────────────┐ │                  │ ▼                  ▼Database       AI Engine │                  │ └──────┬───────────┘        ▼ Decision Engine        ▼ Compliance Engine        ▼ Supplement Package8.
