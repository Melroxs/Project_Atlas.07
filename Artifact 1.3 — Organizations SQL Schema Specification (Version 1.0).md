Artifact 1.3 — Organizations SQL Schema Specification (Version 1.0)PurposeThis specification defines the PostgreSQL implementation of the organizations table.It is the root table of the Atlas multi-tenant database and establishes tenant isolation for the entire platform.Database ObjectTable Name:organizationsPrimary KeyColumn	Type	Constraintid	UUID	PRIMARY KEYGeneration:UUID v7 Delete StrategyAtlas should not physically delete organizations.Instead:archived_at IS NULLindicates an active organization.Archived organizations remain available for reporting, auditing, and historical reference.Foreign Key UsageThe organizations.id value becomes the parent key referenced by nearly every operational table, including:usersteamscustomerspropertiesclaimsdocumentsphotostasksai_sessionssupplementsreportsintegrationsaudit_logsAll child tables should include an indexed organization_id foreign key to enforce tenant isolation.Migration RulesBefore applying the migration:Confirm enum definitions.Confirm unique constraints.Confirm index names follow project conventions.Ensure
