# EVIDENCE_GRAPH_SPEC.md## PurposeThe Atlas Evidence Graph is the central intelligence layer that connects every entity, document, photo, communication, workflow event, estimate, supplement, and AI observation into a unified knowledge graph.Instead of storing isolated records, Atlas models relationships between objects so that every recommendation is explainable, traceable, and supported by evidence.---# VisionAtlas should answer questions such as:* Why is this supplement being recommended?* Which photos support this line item?* Which inspection notes contradict the estimate?* What evidence is still missing?* Which adjuster approved similar supplements?* Which documents reference this room?* What events happened before the mitigation inspection?* Which conversations mention mold?Every answer should be backed by connected evidence.---# ObjectivesThe Evidence Graph enables:* Explainable AI* Complete claim traceability* Cross-document reasoning* Automatic evidence linking* Semantic search* Compliance validation* Supplement justification* Organizational knowledge---# Core Principles1. Every object is a node.2. Every relationship is explicit.3. Nothing exists in isolation.4. Every AI conclusion is explainable.5. Every recommendation is traceable.6. Every relationship is timestamped.7. Human actions remain auditable.---# Graph ArchitectureThe graph consists of:* Nodes* Relationships* Properties* Events* Evidence* Confidence metadata* Version history---# Primary Node Types## ClaimsContains:* Claim Number* Carrier* Policy* Insured* Property* Status---## ProjectsRepresents restoration projects linked to claims.---##
