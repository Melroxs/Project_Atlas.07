# Database Observability---PurposeMonitors operational health and capacity.---MetricsQuery latency.Connection count.CPU.Memory.Disk usage.Index utilization.Cache hit ratio.Replication health.Backup status.Migration status.Storage growth.Vector search latency.---AlertsFailed backups.High latency.Deadlocks.Storage thresholds.Replication lag.Job backlog.Security anomalies.
