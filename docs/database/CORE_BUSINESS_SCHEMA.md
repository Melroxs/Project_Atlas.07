# Core Business SchemaVersion: 1.0Status: Approved---# OverviewThe Core Business Schema defines the primary operational entities used throughout Atlas.These entities provide:- Multi-tenant isolation- User identity- Restoration company structure- Claims management- Customer management- Insurance information- Property informationEvery operational workflow depends on these entities.---# Primary EntitiesOrganization↓Teams↓Users↓Projects↓Claims↓Properties↓Customers↓Insurance Companies↓Policies↓Adjusters---# Global RulesEvery table contains:id UUID PRIMARY KEYorganization_id UUIDcreated_at TIMESTAMPTZupdated_at TIMESTAMPTZdeleted_at TIMESTAMPTZ NULLcreated_by UUIDupdated_by UUIDversion INTEGER DEFAULT 1---Soft DeleteBusiness records are never physically deleted.deleted_at indicates archival.---OwnershipEvery operational record belongs to one organization.Cross-tenant relationships are prohibited.---AuditEvery CREATEEvery UPDATEEvery DELETEcreates an Activity Event.---UUID StrategyUUID v7 preferred.Fallback UUID v4.
