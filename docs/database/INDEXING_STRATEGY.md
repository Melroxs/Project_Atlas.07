# Database Indexing StrategyVersion: 1.0Status: Approved---# PurposeDefines indexing standards to ensure predictable query performance while minimizing write amplification.---## Index TypesPrimary Key IndexesUnique IndexesForeign Key IndexesComposite IndexesPartial IndexesGIN IndexesGiST IndexesIVFFlat / HNSW Vector IndexesBRIN Indexes (future)---## Standard RulesEvery Primary Key indexed.Every Foreign Key indexed.Every unique constraint indexed.Frequently filtered columns indexed.Frequently joined columns indexed.Vector columns indexed using pgvector.---## Composite Index ExamplesClaimsorganization_idclaim_statusloss_date---Documentsorganization_idclaim_iddocument_type---Supplementsclaim_idstatusconfidence_score---AI Decisionsclaim_iddecision_typecreated_at---Performance TargetsSimple lookup< 10 msTenant-filtered queries< 50 msDashboard queries< 200 msVector retrieval< 500 ms
