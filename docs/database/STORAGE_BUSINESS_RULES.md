# Storage Business Rules1. Every document belongs to exactly one organization.2. Binary files are stored in object storage; metadata is stored in PostgreSQL.3. Every upload receives a cryptographic checksum.4. File versions are immutable and fully auditable.5. OCR output is retained and versioned.6. Photos preserve original EXIF metadata whenever available.7. AI-generated annotations are stored separately from original media.8. Export packages are reproducible from versioned source data.9. Every file operation generates an audit event.10. Search indexes are updated asynchronously after content changes.11. Storage buckets inherit organization-level security through Row-Level Security and signed URL policies.12. All storage operations support future compliance, retention, and legal hold requirements.
