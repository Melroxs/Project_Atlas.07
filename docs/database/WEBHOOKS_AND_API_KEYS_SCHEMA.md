# Webhooks & API Keys Schema---PurposeSupports secure integrations with external systems.---Tablesapi_keyswebhookswebhook_eventswebhook_deliveries---## api_keysColumnsidorganization_idnamekey_prefixhashed_secretpermissions_jsonexpires_atlast_used_atstatuscreated_at---## webhooksColumnsidorganization_idendpoint_urlsecretevent_filterstatuscreated_at---Business RulesSecrets stored hashed or encrypted.Webhook retries exponential.Delivery signatures required.
