# Infrastructure Business Rules1. Every background job must be idempotent.2. All significant domain actions emit immutable events.3. Notifications honor user preferences and organization policies.4. API keys are hashed, scoped, and revocable.5. Webhook deliveries are signed and retried using exponential backoff.6. Integration credentials are encrypted and rotated according to security policy.7. Cache entries are treated as ephemeral and can be regenerated from authoritative data.8. Analytics events are immutable and aggregated asynchronously.9. Feature flags support gradual rollout and immediate rollback.10. Configuration changes are versioned and auditable.11. Infrastructure services inherit organization ownership where applicable and enforce Row-Level Security.12. Every asynchronous process records execution metrics, errors, and retry history.
