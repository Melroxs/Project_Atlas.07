# EVIDENCE-002 — Atlas Evidence Graph Database Schema**Document ID:** EVIDENCE-002**Version:** 1.0**Status:** Draft**Owner:** Atlas Engineering---# PurposeThis document defines the database schema for the Atlas Evidence Graph.The schema supports:- Evidence storage.- Evidence relationships.- Confidence scoring.- Source attribution.- AI reasoning traceability.- Decision support.---# Database Design PrincipleEvery Atlas recommendation must answer:1. What evidence was used?2. Where did the evidence come from?3. How strong is the evidence?4. Who approved the action?---# Entity Relationship Overview```                    Claim                      |                Evidence Nodes                      |        --------------------------------        |              |               |    Documents       Photos        Estimates                      |              Evidence Relationships                      |              Decision Engine                      |             Recommendations```---# Table 1 — evidence_nodes## PurposeStores every object that can participate in reasoning.---## Schema```evidence_nodesidorganization_idclaim_idnode_typesource_typesource_idtitledescriptionconfidence_scoremetadata JSONBcreated_atupdated_at```---# Fields| Field | Type | Description ||-|-|-|| id | UUID | Evidence identifier || organization_id | UUID | Tenant || claim_id | UUID | Related claim || node_type | ENUM | Evidence object type || source_type | ENUM | Origin || source_id | UUID | Original record || title | VARCHAR | Display name || description | TEXT | Explanation || confidence_score | DECIMAL | AI confidence || metadata | JSONB | Additional data || created_at | TIMESTAMP | Creation time || updated_at | TIMESTAMP | Last update |---# Node Types```CLAIMDOCUMENTPHOTOESTIMATE_ITEMPOLICY_REQUIREMENTDAMAGE_AREAMATERIALRECOMMENDATION```---# Source Types```USERDOCUMENT_AICOMPUTER_VISIONSYSTEMEXTERNAL_IMPORT```---# Table 2 — evidence_relationships## PurposeStores connections between evidence nodes.---## Schema```evidence_relationshipsidorganization_idfrom_node_idto_node_idrelationship_typeconfidence_scorereasoningcreated_bycreated_at```---# Relationship Types```SUPPORTSCONTRADICTSREQUIRESDERIVED_FROMMATCHES```---# Example```Photo Node      | SUPPORTS      |Estimate Item Node```---# Table 3 — evidence_sources## PurposeTracks original evidence origin.---## Schema```evidence_sourcesidorganization_idsource_typesource_idlocationcreated_at```---# ExamplesSource:```DocumentEstimate.pdf```Source:```PhotoIMG_001.jpg```---# Table 4 — evidence_observations## PurposeStores AI observations.---## Schema```evidence_observationsidorganization_idevidence_node_idobservation_typeobservation_data JSONBconfidence_scorecreated_at```---# Observation Types```DAMAGE_DETECTEDMATERIAL_IDENTIFIEDMISSING_SCOPEPOLICY_CONDITIONRISK_FOUND```---# Example Observation```Observation:Missing roof flashingConfidence:0.88Evidence:Inspection photo```---# Table 5 — evidence_decisions## PurposeStores reasoning outputs.---## Schema```evidence_decisionsidorganization_idclaim_iddecision_typedecision_statusexplanationconfidence_scorecreated_at```---# Decision Types```SUPPLEMENT_OPPORTUNITYCOMPLIANCE_WARNINGDOCUMENT_REQUESTCLAIM_REVIEW```---# Decision Status```GENERATEDUNDER_REVIEWAPPROVEDREJECTED```---# Table 6 — evidence_decision_sources## PurposeLinks decisions back to evidence.This provides explainability.---## Schema```evidence_decision_sourcesiddecision_idevidence_node_idrelationshipcreated_at```---# ExampleDecision:```Supplement Opportunity```Sources:```Photo #123Inspection ReportEstimate Item #456```---# Table 7 — evidence_activity_log## PurposeTracks evidence changes.---## Schema```evidence_activity_logidorganization_idevidence_node_idactionperformed_bymetadata JSONBcreated_at```---# Activity Types```EVIDENCE_CREATEDRELATIONSHIP_CREATEDCONFIDENCE_UPDATEDDECISION_GENERATEDDECISION_APPROVED```---# Index StrategyRequired indexes:```evidence_nodes_claim_idxevidence_nodes_type_idxevidence_relationships_source_idxevidence_relationships_target_idxevidence_decisions_claim_idx```---# Query Examples## Find Evidence Supporting Supplement```Claim↓Recommendations↓Evidence Sources↓Supporting Documents```---## Find Missing Evidence```Required Evidence-Available Evidence=Evidence Gap```---# AI Reasoning StorageAtlas stores:```Input Evidence+Relationship+Confidence+Decision+Explanation```Example:```Recommendation:Add flashing scopeReason:3 photos show damageEstimate missing itemConfidence:0.91```---# Security ModelEvery evidence query requires:```Organization ID+Claim Permission+Audit Validation```---# Migration OrderCreate tables:```1. evidence_nodes2. evidence_sources3. evidence_relationships4. evidence_observations5. evidence_decisions6. evidence_decision_sources7. evidence_activity_log```---# Acceptance CriteriaEvidence Graph database is complete when:✅ Evidence nodes can be created✅ Relationships can be stored✅
