# DOCUMENT-002 — Atlas Document Database Schema**Document ID:** DOCUMENT-002**Version:** 1.0**Status:** Draft**Owner:** Atlas Engineering**Depends On:**- DOCUMENT-001 Document Intelligence Architecture- CLAIM-002 Claims Database Schema- Evidence Graph Specification- PLAT-005 Audit Logging Framework---# PurposeThis document defines the database schema for Atlas Document Intelligence.The schema supports:- Document storage metadata.- Claim relationships.- Document processing.- AI extraction.- Evidence connections.- Document history.---# Database Design PrinciplesDocuments must be:- Traceable.- Searchable.- Versioned.- Auditable.- Connected to evidence.A document is never treated as an isolated file.It is a source of business intelligence.---# Entity Relationship Overview```Organization      |    Claim      |  Documents      | ----------------------VersionsAI ExtractionsEvidence LinksActivities----------------------```---# Table 1 — documents## PurposePrimary document record.Stores metadata about uploaded files.---## Schema```documentsidorganization_idclaim_idfile_namefile_typemime_typestorage_pathdocument_categorystatusuploaded_bycreated_atupdated_atdeleted_at```---# Fields| Field | Type | Description ||-|-|-|| id | UUID | Document identifier || organization_id | UUID | Tenant owner || claim_id | UUID | Related claim || file_name | VARCHAR | Original filename || file_type | VARCHAR | Extension || mime_type | VARCHAR | File format || storage_path | TEXT | Storage location || document_category | ENUM | Document classification || status | ENUM | Processing state || uploaded_by | UUID | User uploader || created_at | TIMESTAMP | Creation date || updated_at | TIMESTAMP | Last update || deleted_at | TIMESTAMP | Soft delete |---# Document Status```UPLOADEDPROCESSINGEXTRACTEDVALIDATEDLINKEDREADYARCHIVEDFAILED```---# Document Categories```POLICYESTIMATEREPORTINVOICEPHOTOCORRESPONDENCECONTRACTOTHER```---# IndexesRequired:```documents_claim_idxdocuments_organization_idxdocuments_status_idxdocuments_category_idx```---# Table 2 — document_versions## PurposeMaintains document history.Documents may be replaced or updated.---## Schema```document_versionsiddocument_idversion_numberstorage_pathuploaded_bycreated_at```---# Example```Estimate.pdfVersion 1↓Estimate.pdfVersion 2```---# Table 3 — document_processing_jobs## PurposeTracks AI processing tasks.---## Schema```document_processing_jobsidorganization_iddocument_idjob_typestatusstarted_atcompleted_aterror_messagecreated_at```---# Job
