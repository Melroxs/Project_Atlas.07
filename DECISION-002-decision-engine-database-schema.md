# DECISION-002 — Atlas Decision Engine Database Schema**Document ID:** DECISION-002**Version:** 1.0**Status:** Draft**Owner:** Atlas Engineering---# PurposeThis document defines the database schema required for the Atlas Decision Engine.The schema supports:- AI recommendations.- Decision scoring.- Risk analysis.- Evidence traceability.- Human approvals.- Audit history.---# Database Design PrincipleEvery Atlas decision must store:```Decision+Evidence+Reasoning+Confidence+Human Outcome```---# Entity Relationship Overview```                    Claim                      |              Decision Records                      |        ----------------------------        |            |             |   Evidence      Scores       Approvals        |   Recommendations```---# Table 1 — decisions## PurposeStores the primary decision generated by Atlas.---## Schema```decisionsidorganization_idclaim_iddecision_typestatustitledescriptionrecommendationconfidence_scorerisk_scoreprioritycreated_bycreated_atupdated_at```---# Fields| Field | Type | Description ||-|-|-|| id | UUID | Decision identifier || organization_id | UUID | Tenant || claim_id | UUID | Related claim || decision_type | ENUM | Type of decision || status | ENUM | Workflow status || title | VARCHAR | Decision title || description | TEXT | Explanation || recommendation | TEXT | Suggested action || confidence_score | DECIMAL | AI confidence || risk_score | DECIMAL | Risk level || priority | ENUM | Importance || created_by | UUID | Creator || created_at | TIMESTAMP | Creation time || updated_at | TIMESTAMP | Last update |---# Decision Types```SUPPLEMENT_OPPORTUNITYCOMPLIANCE_WARNINGDOCUMENT_REQUESTCLAIM_REVIEW```---# Decision Status```GENERATEDUNDER_REVIEWAPPROVEDREJECTEDARCHIVED```---# Priority Levels```LOWMEDIUMHIGHCRITICAL```---# Table 2 — decision_scores## PurposeStores detailed scoring calculations.---## Schema```decision_scoresiddecision_idevidence_scorecoverage_scorecompliance_scorerisk_factor_scorefinal_scorecalculation_details JSONBcreated_at```---# Example```Evidence Score:0.92Coverage Score:0.85Compliance Score:0.90Final Score:0.89```---# Table 3 — decision_evidence_links## PurposeConnects decisions to supporting evidence.---## Schema```decision_evidence_linksiddecision_idevidence_node_idrelationship_typeimportance_scorecreated_at```---# Relationship Types```SUPPORTSPRIMARY_REASONSECONDARY_REASONRISK_INDICATOR```---# ExampleDecision:```Supplement Opportunity```Evidence:```Damage PhotoInspection ReportEstimate Gap```---# Table 4 — decision_risks## PurposeStores risks identified by Atlas.---## Schema```decision_risksiddecision_idrisk_typeseveritydescriptionmitigationcreated_at```---# Risk Types```MISSING_DOCUMENTATIONINSUFFICIENT_EVIDENCECOMPLIANCE_FAILURECONFLICTING_INFORMATIONREVENUE_LEAKAGE```---# Severity```LOWMEDIUMHIGHCRITICAL```---# Table 5 — decision_actions## PurposeStores recommended next actions.---## Schema```decision_actionsiddecision_idaction_typedescriptionstatusassigned_tocompleted_at```---# Action Types```REVIEWREQUEST_DOCUMENTUPDATE_ESTIMATECONTACT_ADJUSTERSUBMIT_SUPPLEMENT```---# Action Status```PENDINGIN_PROGRESSCOMPLETEDCANCELLED```---# Table 6 — decision_approvals## PurposeStores human review outcomes.---## Schema```decision_approvalsiddecision_idreviewer_idapproval_statuscommentscreated_at```---# Approval Status```APPROVEDREJECTEDREQUEST_CHANGES```---# Example```AI Recommendation        ↓Human Review        ↓Approved        ↓Action Created```---# Table 7 — decision_reasoning_logs## PurposeStores explainability information.---## Schema```decision_reasoning_logsiddecision_idreasoning_typeinput_data JSONBoutput_data JSONBcreated_at```---# Reasoning Types```EVIDENCE_ANALYSISCOMPLIANCE_CHECKRISK_ASSESSMENTSUPPLEMENT_ANALYSIS```---# Example Reasoning Record```Input:3 damage photosEstimate comparisonInspection reportOutput:Potential missing scope detectedConfidence:0.91```---# Index StrategyRequired indexes:```decisions_claim_idxdecisions_status_idxdecisions_type_idxdecision_evidence_links_decision_idxdecision_scores_decision_idxdecision_actions_status_idx```---# Query Examples## Find Open Supplement Opportunities```Claim↓Decisions↓Type:SUPPLEMENT_OPPORTUNITY↓Status:UNDER_REVIEW```---## Explain DecisionQuery:```Decision+Evidence Links+Reasoning Logs+Approval History```Returns:```WhyHowConfidenceWho approved```---# Security ModelEvery decision query requires:```Organization ID+Claim Permission+Audit Verification```---# Migration OrderCreate tables:```1. decisions2. decision_scores3. decision_evidence_links4. decision_risks5. decision_actions6. decision_approvals7. decision_reasoning_logs```---# Acceptance CriteriaDecision Engine database is complete when:✅ Decisions can be stored✅ Scores are persisted✅ Evidence links exist✅ Risks are tracked✅ Actions can be assigned✅ Human approval is recorded✅ Reasoning is explainable---# Next Document## DECISION-003 — Decision Engine Domain TypesThis defines the
